## 🚀 Projetos em destaque

### 🛡️ FlowGuard — Automação e Monitoramento Kanban

MVP funcional desenvolvido durante minha **Iniciação Científica**, com integração à API do Trello para apoiar o acompanhamento de fluxos de trabalho ágeis.

O sistema utiliza automação baseada em regras para sinalizar **possíveis gargalos**, acompanhar limites de trabalho em andamento (WIP) e reunir informações sobre impedimentos em uma dashboard web responsiva.

Também inclui um **Power-Up integrado ao Trello**, permitindo visualizar informações diretamente na plataforma.

**Tecnologias:** JavaScript • Node.js • Express • Axios • HTML • CSS • Trello REST API • Trello Power-Up

🔗 [Explorar o projeto no GitHub](https://github.com/stumpfdenise/bot-trello-gargalos)

🌐 [Experimentar o dashboard](https://bot-trello-gargalos.onrender.com/dashboard.html)

**📄 Pesquisa e publicação acadêmica**

O FlowGuard integra a pesquisa **“Integração de Bots em Projetos Ágeis: Menos Gargalos, Mais Resultados”**, desenvolvida durante minha Iniciação Científica e publicada nos **Anais Eletrônicos do XIV EPCC — Encontro Internacional de Produção Científica da UniCesumar**.

📖 [Acessar publicação acadêmica](https://static.even3.com/anais/1318954.pdf)
